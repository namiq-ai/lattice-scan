# lattice-scan 0.6.1

**Switches off four features of 0.6.0 that needed a published dataset.** `--discover --all`, `project --discover --all`, `lattice-scan index` and `posture --attack` downloaded a signed list of every exploited CVE and a table of ATT&CK techniques. That data is no longer published, so these features no longer work. Upgrade so they say so plainly instead of failing with a network error.

## What changed

- `--discover --all`, `project --discover --all`, `lattice-scan index` and `posture --attack` print "not available in this version" on stderr, exit 2 and fetch nothing.
- Everything else from 0.6.0 is unchanged: the `exposure:` line, `--exposed`, `--fail-on exposed`, snapshots and "change since the last run", the COVERAGE line, and the stable posture signal codes.
- `--discover --monthly` (the last 30 days) and `--discover --open` (deadlines already passed) still list named CVEs. `recent --all` is unchanged.

## What is not in this release

- Checking old software one item at a time on the server is planned and not built yet. Until then `--all` has no replacement.

## 0.6.0 notes that no longer hold

The 0.6.0 notes described `--discover --all`, `lattice-scan index` and `posture --attack` as available. They are not. The 0.6.0 and 0.5.0 sections of the changelog are left as history.

## Install and verify

`pip install lattice-scan==0.6.1`, or `uv tool upgrade lattice-scan`; the signed apt repository at https://namiq.io/apt after the repository update. Check with `lattice-scan --version`.
