# lattice-scan 1.1.3

**A report request is no longer refused after you confirm the mailbox: the client sends only the words the service accepts for what a run does not check.**

Corpus: precision 1.00, recall 1.00 on 12 synthetic host cases (without the distribution verdict: 0.80, 0.67)

## What changed

- `--report` waits up to 3 minutes for you to press Confirm in the mail and goes on by itself in the same run: it sends the report and prints the request id, what happens next (a person reviews it, a download link goes to the masked address, type the code) and the 6-digit code once. A person with no key gets the free key at the same Confirm. No second command in the normal case.
- Not confirmed in time, or Ctrl-C: the request is kept for an hour and `lattice-scan report finish` sends it later. `--no-wait` never waits.
- The record's `coverage.notChecked` words are now the accepted closed list: `php`, `java`, `ruby`, `go`, `dotnet` (the browser is checked, so `browser` is not sent). Before, the client sent a different set of words and the service refused the whole request with "a coverage notChecked word is not one of the listed words".
- A new test fails if the client can send a word outside the accepted lists for coverage, distribution status, match basis or changelog.
- A request saved by 1.1.1 or 1.1.2 carries the old words. Run the scan with `--report` again.

## Install and verify

`pipx install lattice-scan` or `apt upgrade lattice-scan` once the repository is updated; `lattice-scan --version` prints 1.1.3.
