# lattice-scan 0.9.0

**lattice-scan now reads a Mac. This is the first release of macOS support: treat a result as a lead, and tell us what you see.**

## What is new

- **macOS host scan.** `lattice-scan --cve CVE-...`, `lattice-scan recent` and `lattice-scan --refresh --inventory` now work on a Mac. The tool reads, from files only: the macOS version (and the letter of a background security improvement such as `(a)`, if one is installed), the apps in /Applications and /System/Applications, the names and versions in the Homebrew Cellar folders, and the Mac's model and chip from the hardware overview. It never runs `brew`, never opens a folder macOS protects with a permission dialog (Desktop, Documents, Downloads, iCloud, Photos, Library), and sends nothing new: only CVE ids go to Lattice, as on Linux.
- **How a Mac is judged.** NVD's own product names decide what a CVE is about: `apple/macos` is the system, and any other `apple/<name>` (for example Safari) counts when an app of that name is installed. Apple fixes each macOS release on its own, so only ranges that belong to your release are compared. A release Apple lists no range for (macOS 12 and 13 for most entries), and a Mac with a security-improvement letter, come back **undetermined**, never "fixed". iOS, iPadOS, watchOS, tvOS and visionOS entries are not applied to a Mac.
- **The "a scan ran" note** gains one field, the operating-system family: the word `linux` or `macos`, no version, name or build. It is for counting Mac scans. The notice that explains the note is shown once more. Off with `LATTICE_SCAN_NO_REPORT=1`, as before.
- **A written report.** A scan that finds candidates writes a plain-text report to `reports/` in the records folder (mode 0600). Nothing is sent.

## What changed

- On a Mac, `--discover --all`, `posture` and `inventory --share` still stop with a message and exit 3; they cannot read a Mac yet.
- Fixed: the 30-day limit for notes kept while offline now counts in UTC, like the notes themselves.
- CI runs on a real Mac (macOS 15) for the Mac reading and the stop.

## What is not in this release

- Posture (ports, firewall, services) and the item checks of `--discover --all` on a Mac.
- Tested macOS versions: 15 and 26, on hosted Apple-silicon machines only. macOS 12, 13, 14 and 27, Intel Macs, and a Mac with a real security-improvement letter have not been tried; they are read the same way.
- No Homebrew formula yet.
- No verdict is a finding. A result is a lead for a person to read.

## Install and verify

`pip install --upgrade lattice-scan` (or the apt package, or the Claude Code plugin). `lattice-scan --version` prints 0.9.0. Check the checksums in `SHA256SUMS` against the release assets. On a Mac, `lattice-scan --refresh --inventory` prints the macOS version, the apps read and the Homebrew formulae, and sends nothing.
