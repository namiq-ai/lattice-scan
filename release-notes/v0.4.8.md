# lattice-scan 0.4.8

**Give the Lattice Analyst what you run.** `lattice-scan inventory --share` prints the important software of this host as one block you copy and paste into My products at lattice.namiq.io/chat. The Analyst then says which of today's CISA-exploited CVEs may concern you, with the item that matched and the version to compare, and explains the posture lines. Nothing about your host leaves it except what you paste.

## What is new

- `lattice-scan inventory --share`: a `LATTICE INVENTORY v1` block of at most 150 lines and 12 KB. It lists the kernel, what listens (with the owning package), any installed item the tool's own matcher links to an entry of today's CISA list, the running container images, snaps and a curated list of server, edge and admin software, each with the reason it is listed, and the firewall and SSH settings. The format is in `docs/INVENTORY-BLOCK.md`.
- It names software and versions only: no host name, address, user name, serial or path (a test puts a canary through every field).
- It reads namiq.io's public recent list once, so nothing the list could concern is dropped from a full block. `--no-feed` skips that and the block says so. `--max-lines N` lowers the cap. `--all FILE` writes every package, snap and image to a private file (mode 0600), never to the console.

## Who can use it and how

Anyone with the tool. `pipx install lattice-scan` (or the signed apt repository, or the Claude skill), then `lattice-scan inventory --share`, copy from `LATTICE INVENTORY v1` to `end`, paste into My products.

## What changed and what did not

Everything else is unchanged: the scan, `recent`, `project`, `posture`, the inventory log. What leaves the machine is still CVE ids (and a key if you set one) plus the one public request for the recent list.

## Known limits

- A host with fewer than a few packages gives a short block; that is correct.
- Without root, the owner of a listening socket may be unknown; the line then has no `owner=`.
- The curated list is a reviewed list of names, not a judgement about what is vulnerable. A candidate is a lead for you to check.
- The format is version 1; the reader skips lines it does not know.

## Install and verify

`pip install lattice-scan==0.4.8`, or `uv tool upgrade lattice-scan`; the signed apt repository at https://namiq.io/apt after the repository update; assets on the release: `lattice-scan.pyz`, the `.deb`, the wheel, the plugin ZIPs and `SHA256SUMS` (`sha256sum -c SHA256SUMS`).
