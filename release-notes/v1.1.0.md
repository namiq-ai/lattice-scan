# lattice-scan 1.1.0

**The distribution's own verdict is now sent by default, without a question, and the tool prints what it sends first. `--no-distro` turns it off.**

Corpus: precision 1.00, recall 1.00 on 12 synthetic host cases (without the distribution verdict: 0.80, 0.67)

## What changed

- A host scan that matches packages by identity sends, for each matched package only, its source package name, ecosystem, version and OS release, so Lattice can answer with the distribution's own fixed version. Before 1.1.0 it asked first.
- The tool prints a notice of what it sends before it sends it, on every run and even with `--quiet`. The full list is in the progress lines.
- `--no-distro` or `LATTICE_SCAN_ITEM_VERDICT=off`: nothing is sent for it, and the verdict compares upstream numbers as before.
- Never sent: the host name, addresses, ports, paths, user names, the package list as a whole, or an image name.
- No question means a script or CI job never waits, with or without a terminal.
- With no connection nothing is asked or sent: a verdict saved on an earlier run is used and labelled with its date, and a package with none keeps the upstream comparison. One missing verdict no longer stops the others.
- The report step stays opt-in with `--report` (1.0.1).

## Known

- 1.0.0 was never published; 1.0.1 and this release carry its changes. The emailed report remains a trial feature until 31 December 2026.
- Counsel has not answered on sending without a prompt; the owner accepted the change on 2026-11-15 with a printed notice and an off switch.

## Install and verify

`pipx install lattice-scan` or `apt upgrade lattice-scan` once the repository is updated; `lattice-scan --version` prints 1.1.0 and `lattice-scan --help` lists `--no-distro`.
