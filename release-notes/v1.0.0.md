# lattice-scan 1.0.0

**This release turns on the emailed report as a trial feature until 31 December 2026. A scan that finds a candidate asks once whether to send a report by email; the default is No.**

Corpus: precision 1.00, recall 1.00 on 12 synthetic host cases (without the distribution verdict: 0.80, 0.67)

## What is new

- **Emailed report (trial).** After a scan with at least one candidate, a person at a terminal is asked once whether to send a report by email. Enter means No, `d` shows every value that would be sent. Nothing is asked in a script, in CI, with `--quiet`, with `--format json|csv`, or after the trial ends. An agent never answers it.
- **Registered address only, with a report code.** The report goes only to the address registered with your key. After it is sent, the terminal shows a six-digit code in bold once; you need it to open the report from the link in the mail. It is not emailed and not written to any file or log.
- **Free, as is.** The consent screen says the report is free, is provided as is and may contain mistakes, that a person at NamiQ reads the findings to review it, and how long it is kept.
- **A more accurate local report.** One verdict per package, running assets first and none cut off, NOT CHECKED shown apart from ruled out, the host's own OS name, one action line per open running package.

## What did not change

- What a scan reads from the machine. The six extra record fields and the distribution check are sent only with a yes to the report offer.
- The terminal flow that gives a person with no key a free key: still off.
