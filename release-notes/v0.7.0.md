# lattice-scan 0.7.0

**Checks older software one item at a time.** `--discover --all` and `posture --attack` work again, in a new way: the tool shows you exactly what it will send, asks, and sends one item per request to Lattice, which answers from its graph. The compiled dataset of exploited CVEs is not published and nothing is downloaded.

**This release needs the Lattice server's item tools to be switched on** (`graph_affects`, `graph_exposure`). Until they are, `--discover --all` and `posture --attack` stop with the server's "tool not found" answer. Everything else in the tool works as in 0.6.1.

## What is new

- `lattice-scan --discover --all` has levels. **Level 1, no key:** this machine (operating system, kernel, maker, model, firmware), the operating system of each container image, and what listens or runs as a service. **Level 2, with a key:** those, then foundational packages (C library, TLS, SSH, systemd, sudo ...), well-known server software and the other packages in name order, until your allowance ends. What was not scanned is counted and printed. **Level 3,** every package in depth, is the paid report, which is not on sale yet.
- Before anything is sent the tool prints each item exactly as it goes (a product or package name, its version, sometimes the package system and the operating-system family and number such as "Ubuntu 26.04") and asks. `--yes` skips the question for scripts; with no terminal and no `--yes` nothing is sent. Never sent: host name, addresses, ports, paths, user names, passwords, the package list as a whole, or the packages inside images.
- The server does not tie an item to your key, your address or the time of day, and counts each item anonymously per day.
- `posture --attack` sends the posture signal codes it found (fixed labels such as `ssh.password-auth`), one at a time, and prints the ATT&CK techniques each may point to.
- When the per-minute limit is reached the run waits, at most 5 times in all; when your allowance ends it stops with what it has and exits 3.
- New options: `--yes`, `--quick` (level 1 even with a key), `--also PACKAGE`, `--max-items N`.

## What changed

- Removed the downloader for the signed index and the ATT&CK table (`lattice-scan index`, and the modules behind it).

## What is not in this release

- `project --discover --all` stays off: dependency names of a project can be private.
- No verdict is a finding. A result is a lead for a person to read: names are matched and versions are compared as upstream numbers; a distribution can fix a CVE under an unchanged version number.
- The paid report (level 3) is not on sale.

## Install and verify

`pip install --upgrade lattice-scan` (or the apt package, or the Claude Code plugin). `lattice-scan --version` prints 0.7.0. Check the checksums in `SHA256SUMS` against the release assets.
