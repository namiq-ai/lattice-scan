# lattice-scan 0.9.4

**No change to what a scan prints, reads or sends. This release carries code for report accuracy fields that is switched off.**

## What is new

- **Report accuracy fields, switched off.** The scan record can hold six more fields (which asset a package is on, the distribution's status, how a match was made, whether the changelog names the CVE, per-package versions, what the run covered). They are off in this build: the record is byte-identical to 0.9.3, and the validator refuses the new fields. Turning them on needs the service that accepts them, the owner's decision on the privacy wording, and a later release.
- **Image packages keep their image.** Once those fields are on, a package inside a container image that joined by package identity is named with its image and not as a host package.

## What did not change

- What a scan reads from the machine, and what it sends (CVE ids and returned node ids, and the key).
- The mail offer for a report: still off.
