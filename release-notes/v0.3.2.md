# lattice-scan 0.3.2

**The skill reads NamiQ's own notes first.** When someone asks Claude or Codex what a CVE means, what to do about it, or whether a fix exists, the skill now points the agent at the notes NamiQ publishes before any outside site. This release changes only the text of the skill. The command-line tool behaves exactly as in 0.3.1, and what leaves the machine is unchanged.

## Highlights

- **Where the skill sends the agent.** A table in the skill lists NamiQ's pages and how to find each: the note for one CVE (through the sitemap, by the lowercase CVE id in the address), today's exploited-in-the-wild watch and daily highlight, all security notes, the month's highlight, the page for a weakness class (CWE), and the analysis report behind a note. They carry their sources and need no key.
- **Same rules as before.** The skill quotes a note's mitigations and never applies them. It says what the tool printed, as candidates for a person to confirm, and never calls a host vulnerable or safe.
- **The OpenAI package** attached to this release carries the same skill text, without the key procedure, as before.

## Known limits

- Notes exist for the CVEs NamiQ has written about, not for every CVE. When there is none, the skill says so and goes on to outside sources.
- `recent` lists what was recently added, and matches by product name. An empty or all-`unmatch` result is not the same as safe.
- The host check is tested on Debian-family hosts.
