# lattice-scan 1.0.1

**The report step is now opt-in. Pass `--report` to get the local report and, for a person at a terminal during the trial, the offer to email it. Without it a scan never stops to ask a question.**

Corpus: precision 1.00, recall 1.00 on 12 synthetic host cases (without the distribution verdict: 0.80, 0.67)

## What changed

- `--report` (on a host scan and on `project`) switches the report step on. Without it the tool writes no local report, asks no distribution check and makes no offer to email one, so a script, a CI job or an automation never waits for y/n/all.
- With `--report` nothing else changes from 1.0.0: the local report, then, for a person at a terminal while the trial runs (until 31 December 2026), the offer to email it. The offer is still never made in CI, with `--quiet` or with `--format json|csv`.

## What 1.0.0 introduced and 1.0.1 carries

1.0.0 was merged but never published, so this is the first public release with the emailed report. See the 1.0.0 section of the changelog for the report code, the as-is wording and the registered-address rule.

## Not in this release

The terminal flow that gives a person with no key a free key stays off.

## Install and verify

`pipx install lattice-scan` or `apt upgrade lattice-scan` once the apt repository is updated; then `lattice-scan --version` prints 1.0.1 and `lattice-scan --help` lists `--report`.
