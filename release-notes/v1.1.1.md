# lattice-scan 1.1.1

**`--report` no longer waits at the command line. Press Confirm in the mail, then run `lattice-scan report finish`.**

Corpus: precision 1.00, recall 1.00 on 12 synthetic host cases (without the distribution verdict: 0.80, 0.67)

## What changed

- `--report` asks for the confirmation mail and prints "Report request received. Check your email (h***@n***.io) and press Confirm", then exits. It used to wait up to 15 minutes.
- The request and the record you agreed to send wait in a private file in the records folder (mode 0600, one day at most). Nothing about the machine is sent before the mailbox owner confirms.
- `lattice-scan report finish` asks once whether you confirmed. If so it sends the report and prints the 6-digit code once; if not it says so and changes nothing. It never waits.
- The confirmation link in the mail now points to namiq.io (a website fix, deployed separately).

## Known

- Counsel has not answered on sending without a prompt (1.1.0) or on the emailed report; the report remains a trial feature until 31 December 2026.

## Install and verify

`pipx install lattice-scan` or `apt upgrade lattice-scan` once the repository is updated; `lattice-scan --version` prints 1.1.1 and `lattice-scan report --help` lists `finish`.
