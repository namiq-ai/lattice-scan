# lattice-scan 0.8.1

**On a Mac, the host scan now stops and says so, instead of reporting "no match". And the question before a lookup is shorter and can be remembered.**

## What is new

- **A Mac is not scanned yet, and the tool says so.** `lattice-scan` installs on a Mac, but it reads Linux package databases, so on a Mac every host command (`--cve`, `recent`, `--discover`, `--discover --all`, `--refresh --inventory`, `posture`) used to find nothing and print "no match", which a reader takes as "safe". These commands now print "This computer runs macOS ... would not mean safe" and exit 3. `project FOLDER` and `enrich CVE-...` read no host and keep working on a Mac. Reading a Mac is planned, not built.
- **One short question before a lookup.** `--discover --all` and `posture --attack` now show how many items would be checked, three examples, exactly what is sent and what you get back, then ask `Send? [Y]es / [n]o / [a]lways / [d]etails`. Enter or `y` sends, `d` shows every item, `a` remembers "always" for that kind of lookup. The answer is kept in `consent.json` in the records folder (mode 0600). It applies only at a terminal, so a script or an agent still needs `--yes`; a key makes it a separate kind; a release that sends more fields asks again. `lattice-scan consent` shows what is remembered and `lattice-scan consent forget` removes it.

## What changed

- The question is written to stderr (it used to go to stdout, so it was invisible when the result was redirected to a file). Closed input means no.
- A Mac's kernel number is never compared with Linux kernel entries.
- CI now runs on a real Mac (macOS 15) for the stop and for `project`.

## What is not in this release

- No macOS host scan: no app list, no Homebrew, no macOS version rules. Without them the tool cannot say whether a Mac is affected.
- Scanning is still tested on Debian-family Linux only.
- No verdict is a finding. A result is a lead for a person to read.

## Install and verify

`pip install --upgrade lattice-scan` (or the apt package, or the Claude Code plugin). `lattice-scan --version` prints 0.8.1. Check the checksums in `SHA256SUMS` against the release assets. On a Mac, `lattice-scan --cve CVE-2021-44228` should print the macOS message and exit 3.
