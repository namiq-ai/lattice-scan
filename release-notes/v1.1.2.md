# lattice-scan 1.1.2

**The saved report request is dropped after one hour, the life of the confirmation link.**

Corpus: precision 1.00, recall 1.00 on 12 synthetic host cases (without the distribution verdict: 0.80, 0.67)

## What changed

- `--report` keeps the request and the record you agreed to send in a private file (mode 0600) so that `lattice-scan report finish` can send it after you press Confirm. That file now lives one hour, not a day. Press Confirm in the mail, then run `lattice-scan report finish`; after an hour run the scan with `--report` again.
- Everything else is as in 1.1.1: nothing about the machine is sent before the mailbox owner confirms, and the 6-digit code is shown once, in your terminal, by `report finish`.

## Install and verify

`pipx install lattice-scan` or `apt upgrade lattice-scan` once the repository is updated; `lattice-scan --version` prints 1.1.2.
